# Kevin Ruto Portfolio — GitHub Pages

A responsive, multi-page static portfolio starter with SEO foundations. The site does **not** list SEO as one of Kevin's skills.

## Files
- `index.html` — home
- `about.html` — background and interests
- `projects.html` — project portfolio (starter cards are clearly marked for replacement)
- `engineering.html` — civil engineering learning page
- `contact.html` — contact links to configure
- `assets/css/style.css` — styling and responsive layout
- `assets/js/main.js` — mobile navigation and current year
- `robots.txt`, `sitemap.xml` — search crawler discovery
- `404.html` — GitHub Pages not-found page

## Before publishing
1. In every HTML file, replace `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` with your real public website URL. If your repository is named `YOUR-USERNAME.github.io`, the root URL may be `https://YOUR-USERNAME.github.io/`.
2. Replace the placeholder portrait with your own image. Save it as `assets/images/headshot.jpg` if you want to use the social share image URL, and update the homepage `<img>` to point to `assets/images/headshot.jpg`. Keep an optimized image (ideally WebP or compressed JPEG).
3. Update `robots.txt` and `sitemap.xml` with the same real site URL.
4. Add your actual public email, GitHub profile, and LinkedIn URL in `contact.html`.
5. Replace all project placeholders with real work before presenting them as completed projects. Remove anything that is not accurate.
6. Check all page links after publishing.

## Publish with GitHub Pages
1. Upload the files and folders to the root of your repository (not inside an extra nested folder).
2. Open repository **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for deployment and open the published URL.

## Search visibility
- Register the site in Google Search Console and complete ownership verification.
- Submit `/sitemap.xml`.
- Use URL Inspection to request indexing for the homepage and important pages.
- Indexing and rankings are not guaranteed and may take time.
- Keep the site public and ensure you do not add `noindex` to pages you want indexed.

## Editing
Use any code editor or GitHub's web editor. Search all files for `YOUR-USERNAME` and `YOUR-REPOSITORY` to find URL placeholders. Do not put passwords, service-role keys, or other secrets in public files.
