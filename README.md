# Kevin Kipkemoi Ruto Portfolio

## Publish on GitHub Pages
1. Download and extract this ZIP.
2. Back up your current `kevinruto` repository before replacing anything.
3. Upload the **contents** of this folder (not the enclosing folder) to the repository root. `index.html` must sit at the root.
4. Commit the changes.
5. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
6. Wait for deployment and visit `https://kevihnmtai.github.io/kevinruto/`.

Includes five pages, 404 page, responsive styling, mobile navigation, optimized headshot, favicon, social preview, SEO metadata, sitemap, robots file and a downloadable starter CV.

Important: the LinkedIn URL in the form was typed as `hthttps://www.linkedin.com/in/kevinruto`; this package uses the normalized URL `https://www.linkedin.com/in/kevinruto`. Verify it opens your profile. The contact page uses email and LinkedIn links, so no backend setup is needed. The CV is a starter draft—review before applying. SEO helps discovery but cannot guarantee indexing or ranking.
